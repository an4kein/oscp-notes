    Cross-Site Scripting (XSS) Cheat Sheet

    !!! info "XSS Testing Best Practices" - Try XSS in every input field, host headers, URL redirections, URI parameters, and file upload name fields. - Actions: - Phishing through <iframe>. - Cookie stealing using document.cookie. - Self-conversion to reflected XSS when possible.
