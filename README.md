# 🛡️ OSCP Notes

A curated and structured repository of notes, snippets, commands, payloads, and techniques to help you on your **OSCP journey** (or other certifications and real-world pentests).  
Built with [MkDocs](https://www.mkdocs.org) for fast and beautiful browsing.

🔗 **Live Docs**: [an4kein.github.io/oscp-notes](https://an4kein.github.io/oscp-notes/)

---

## 📚 Sections Covered

- **Enumeration** – Nmap, SMB, LDAP, Web Attacks, VHosts, and more
- **Exploitation** – Payloads, reverse shells, code execution, file transfers
- **Post Exploitation** – AD attacks, privilege escalation, persistence
- **OSCP Tips** – Exam strategy, reporting advice, mental models
- **Cheat Sheets** – Compact commands and fast references
